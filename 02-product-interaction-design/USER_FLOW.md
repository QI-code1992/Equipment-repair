# User Flow

- Baseline: Candidate v1.0
- Status: Awaiting Stage 2 approval

1. 登录并进入授权菜单。
2. 设备管理员从台账查看或维护设备、负责人和知识。
3. 现场人员从故障上报或全局 Agent 选择一台设备并描述现象。
4. 系统校验权限、字段和附件，形成待接单故障。
5. 设备管理员审核诊断和草稿工单并派发。
6. 维修工执行、填写结果并提交验收。
7. 设备管理员验收；系统沉淀知识并更新统一健康分。
8. 管理层通过 BI、详情和智能问数查看真实服务结果。

跨页面跳转前 Agent 先解释目标、权限和影响，用户确认后再跳转。
