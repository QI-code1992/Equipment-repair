# 驾驶舱 BI 页面设计细化

## 1. 页面定位

驾驶舱 BI 面向管理层和组织领导者，用于查看整体经营与运维表现。页面只承载趋势、效率、排行和历史分析，不承担一线待办、故障接单、工单处理或快速处置。

## 2. 页面结构

页面采用单页纵向分析结构：

`管理摘要 → 趋势分析 → 效率分析 → 排行分析 → 历史分析`

### 2.1 顶部标题与筛选

- 标题：驾驶舱 BI
- 副标题：管理层 / 运维质量分析
- 筛选：时间范围、组织、区域、设备类型
- 操作：查询、重置
- 筛选条件对整页数据生效

### 2.2 管理摘要

展示五项聚合指标：设备健康综合评分、故障总数、工单总数、工单按时完成率、平均维修时长（MTTR）。每项显示当前值、单位、较上期变化和小型趋势线，不显示待处理工单数。

### 2.3 趋势分析

展示三张时间趋势图：健康综合评分趋势、故障数量趋势、工单数量趋势。支持日/周/月切换、时间范围联动、图例开关和悬停查看具体值。

### 2.4 效率分析

展示计划工单完成率、平均响应时长、平均维修时长、首次修复率四项聚合指标。每项显示当前值、较上期变化和小趋势线，不展示具体工单列表。

### 2.5 排行分析

展示区域/组织、工厂、车间三类排行，统一支持健康综合评分、工单按时完成率、MTTR 和较上期变化。默认展示前五名，可进入完整分析状态查看更多。

### 2.6 历史分析

底部展示本期、上期、变化值、变化率和近八周趋势。核心字段包括设备总数、健康设备率、故障数量、累计停机时长、工单完成率和 MTTR。

## 3. 与工作台的边界

| 工作台 | 驾驶舱 BI |
|---|---|
| 当前风险 | 整体趋势 |
| 待办任务 | 效率指标 |
| 超时提醒 | 组织排行 |
| 快速处置 | 历史对比 |
| 工单列表 | 聚合分析 |

## 4. 视觉与交互约束

- 延续现有深蓝侧栏、白色顶栏、浅蓝灰背景和蓝色主色。
- 管理摘要使用统一指标卡；趋势、效率、排行和历史分析使用分组面板，避免重复堆叠工作台卡片。
- 页面提供数据空态、加载态和错误态；服务异常时显示计算失败，不使用旧值、零值或空值兜底。
- 图表和排行只用于查看和下钻，不出现“接单、派单、生成工单”等操作按钮。
