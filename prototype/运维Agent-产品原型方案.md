# 运维Agent产品原型方案

## 1、页面目标

运维Agent是平台全局右下角的智能助手入口，目标是在不打断用户当前业务操作的前提下，提供三类高频辅助能力：

1. **AI故障上报**：通过对话收集故障信息，生成“AI待提交”状态的故障单。Agent只负责生成待提交单，不直接提交正式故障流程，最终提交仍由用户在“故障上报”页面完成。
2. **智能问数**：用户可用自然语言查询设备、故障、维修、工单等业务数据。信息不足时Agent主动追问，并调用后台API返回数据结果。
3. **操作指引**：基于当前页面上下文，为用户解释页面功能、操作路径、限制原因和下一步处理建议。

页面定位为“全局辅助工作台”，不是独立业务页面。它应支持用户在任意页面唤起、关闭、再次唤起，并保留各Tab历史对话。

## 2、用户角色

### 2.1 角色定义

| 用户角色 | 可查看范围 | 可编辑/操作范围 |
| --- | --- | --- |
| 有AI悬浮框权限的用户 | 可查看并打开运维Agent；可进入三个Tab；可查看当前Tab历史对话 | 可在三个Tab内发起对话；可清除当前Tab对话；可关闭弹框；可拖拽悬浮入口 |
| 有故障上报权限的用户 | 可查看AI故障上报对话、预览、生成结果 | 可通过AI故障上报生成“AI待提交”故障单；可在故障上报页面对AI待提交单据进行详情、编辑、提交、删除 |
| 无故障上报权限但有AI悬浮框权限的用户 | 可进入AI故障上报Tab并进行咨询、整理故障描述 | 不允许生成“AI待提交”故障单；进入Tab后Agent需自动用对话形式提示权限限制 |
| 有智能问数使用场景的用户 | 可在智能问数Tab查询平台数据 | 可发起问数、追问、复制结果、导出Excel、生成文本报告摘要；智能问数不做数据权限过滤 |
| 普通业务查看用户 | 可使用操作指引理解页面功能和操作路径 | 可复制操作步骤；不具备业务页面权限时，Agent只解释原因，不代替用户完成受限操作 |

### 2.2 权限边界

1. 权限控制到“AI悬浮框”级别，不控制到三个子Tab级别。
2. 不存在“用户有AI悬浮框权限但没有智能问数Tab权限”的情况。
3. 智能问数不做问数时的数据权限校验。
4. AI故障上报需要校验用户是否具备故障上报权限：
   - 有权限：可生成AI待提交故障单。
   - 无权限：可对话咨询和整理内容，但不能生成AI待提交单据。
5. 权限来源为系统管理中的用户管理和角色管理。

## 3、信息架构

### 3.1 全局悬浮入口

| 模块 | 字段/元素 | 说明 |
| --- | --- | --- |
| 悬浮按钮 | 运维Agent入口 | 固定显示在页面右下角，支持拖拽 |
| 拖拽行为 | 纵向拖拽、右侧吸附 | 用户拖动后自动吸附到右侧 |
| 空闲状态 | 半透明 | 3秒无点击、无悬停、无拖拽后，悬浮按钮变为半透明 |
| 打开行为 | 打开右侧弹框 | 点击悬浮按钮打开Agent弹框；打开后悬浮按钮隐藏 |

### 3.2 Agent弹框框架

| 模块 | 字段/入口 | 说明 |
| --- | --- | --- |
| 顶部标题区 | 运维Agent | 标识当前智能助手 |
| 顶部操作 | 清除、关闭 | 清除仅清除当前Tab对话；关闭仅关闭弹框，不清除历史 |
| 子Tab | AI故障上报、智能问数、操作指引 | 三个Tab历史对话互相独立 |
| 对话区 | 用户消息、Agent消息、快捷操作、结果卡片 | 承载不同Tab的对话和结构化内容 |
| 输入区 | 附件按钮、输入框、发送按钮 | 各Tab共用输入区；placeholder和附件含义随Tab变化 |
| 当前页面上下文 | 当前页面名称 | 仅在“操作指引”Tab展示 |

### 3.3 AI故障上报Tab

#### 3.3.1 字段

字段需与“故障上报-新增页”保持一致。

| 字段 | 是否必填 | 来源/规则 |
| --- | --- | --- |
| 选择设备 | 必填 | 通过设备选择器选择；每次仅允许选择1台设备 |
| 所属车间 | 自动带出 | 根据所选设备自动带出 |
| 所属产线 | 自动带出 | 根据所选设备自动带出 |
| 紧急程度 | 必填 | Agent主动询问用户选择；如用户不选择，默认“紧急”，并提示后续可在故障上报页调整 |
| 故障现象 | 必填 | Agent主动询问 |
| 发生时间 | 非必填 | Agent主动询问 |
| 可能故障位置 | 非必填 | Agent主动询问；无“故障部位/系统”字段 |
| 故障说明 | 非必填 | Agent可通过追问补充；最佳填报标准为“现象+条件+影响+已做的临时处置” |
| 现场图片 | 非必填 | 用户可上传 |
| 日志或视频附件 | 非必填 | 用户可上传 |

#### 3.3.2 设备选择器

| 字段 | 说明 |
| --- | --- |
| 设备编号 | 用于唯一识别设备 |
| 设备名称 | 帮助用户确认设备 |
| 所属车间 | 辅助定位 |
| 所属产线 | 辅助定位 |

设备选择器采用弹窗方式，不在对话中以内联卡片直接选择。支持搜索设备编号、设备名称、所属车间、所属产线。

#### 3.3.3 操作入口

| 操作 | 说明 |
| --- | --- |
| 选择设备 | 打开设备选择器 |
| 上传附件 | 上传现场图片、日志或视频 |
| 生成预览 | 在满足必填条件后生成结构化预览 |
| 继续对话 | 继续补充或通过对话修改预览内容 |
| 取消 | 取消当前预览动作，不清除对话 |
| 生成待提交单 | 生成“AI待提交”故障单 |
| 去故障上报页查看 | 跳转至故障上报页面查看AI待提交单据 |

### 3.4 智能问数Tab

| 模块 | 内容 | 说明 |
| --- | --- | --- |
| 对话输入 | 自然语言问题 | 支持多轮追问和条件继承 |
| 条件追问 | 时间范围、对象范围、指标口径等 | 信息不足时Agent主动追问 |
| 默认时间 | 近30天 | 用户未说明时间范围时默认使用近30天，并允许后续修改 |
| 结果展示 | 文本、指标卡、图表、表格 | 根据问题返回合适的数据展示形式 |
| 结果操作 | 复制结果、导出Excel、生成报告摘要 | 支持评审和业务复用 |
| 下钻入口 | 跳转至筛选后的业务页面 | 支持从结果进入对应明细 |

### 3.5 操作指引Tab

| 模块 | 内容 | 说明 |
| --- | --- | --- |
| 当前页面上下文 | 当前页面名称 | 仅本Tab展示 |
| 指引内容 | 页面功能说明、操作路径、限制解释、下一步建议 | 默认短回答，可展开详细步骤 |
| 跨页面流程 | 先确认用户需求，再引导跳转 | 避免尚未理解需求就让用户离开当前页面 |
| 操作入口 | 展开详细步骤、复制步骤 | 不做页面高亮，不自动执行跳转 |

## 4、核心业务流程

### 4.1 全局打开与关闭流程

1. 用户在任意页面看到右下角“运维Agent”悬浮入口。
2. 用户可拖拽入口位置，松手后入口自动吸附到右侧。
3. 3秒无操作后，入口变为半透明。
4. 用户点击入口，打开右侧Agent弹框。
5. 弹框打开后，悬浮入口隐藏，弹框位于悬浮入口上层。
6. 用户点击关闭，弹框关闭，悬浮入口恢复显示。
7. 关闭不清除历史对话；再次打开时回到上次所在Tab。

### 4.2 AI故障上报流程

1. 用户进入“AI故障上报”Tab。
2. Agent自动说明能力并开始收集：  
   “我可以帮你通过对话生成待提交故障单。请先选择设备。”
3. Agent依次收集以下信息：
   - 先问设备。
   - 再问故障现象和紧急程度。
   - 再问发生时间和可能故障位置。
   - 再问是否补充现场图片、日志或视频附件。
4. 上述字段收集不计入额外追问5轮限制。
5. Agent可继续追问其他非必填信息，用于填充故障说明，但最多追问5轮，避免影响用户体验。
6. 必填信息满足后，Agent在生成预览前提示一次缺失项：
   - 必填项已满足。
   - 非必填项如发生时间、可能故障位置、附件等仍可补充。
   - 询问用户是否生成预览。
7. 用户选择生成预览后，Agent展示只读预览。
8. 如用户需要调整预览信息，必须通过“继续对话”让Agent修改，不能直接编辑预览字段。
9. 用户点击“生成待提交单”。
10. 系统生成“AI待提交”故障单，并使用正式故障编号。
11. 用户可跳转到故障上报页面，对AI待提交单据进行详情、编辑、提交、删除。
12. 用户在故障上报页面提交后，状态流转为“待接单”。

### 4.3 智能问数流程

1. 用户进入“智能问数”Tab。
2. 用户输入自然语言问题，例如“近30天故障最多的设备有哪些？”。
3. Agent判断问题条件是否足够。
4. 若条件不足，Agent主动追问。
5. 若用户未说明时间范围，默认按近30天查询，并在回答中说明可继续修改。
6. Agent调用后台API获取数据。
7. Agent返回文本、指标卡、图表或表格。
8. 用户可继续追问，系统继承上一轮条件并重新计算。
9. 用户可复制结果、导出Excel或生成报告摘要。
10. 若结果支持下钻，用户可跳转至筛选后的业务页面。

### 4.4 操作指引流程

1. 用户进入“操作指引”Tab。
2. Agent展示当前页面上下文。
3. 用户询问当前页面功能、某个按钮含义、操作限制或跨页面流程。
4. Agent先理解用户目标，再给出简短指引。
5. 如用户需要更详细内容，可点击“展开详细步骤”。
6. 如涉及跨页面操作，Agent需先说明跳转目的和后续步骤，再由用户决定是否跳转。
7. 用户可复制步骤用于留存或转发。

## 5、状态规则

### 5.1 Agent弹框状态

| 状态 | 规则 |
| --- | --- |
| 未打开 | 显示悬浮入口 |
| 空闲 | 悬浮入口3秒无操作后半透明 |
| 拖拽中 | 悬浮入口跟随用户纵向移动 |
| 已打开 | 显示右侧弹框，隐藏悬浮入口 |
| 已关闭 | 关闭弹框，不清除历史对话 |

### 5.2 Tab历史状态

| 状态 | 规则 |
| --- | --- |
| 首次进入 | 展示该Tab默认欢迎语和快捷问题 |
| 有历史对话 | 保留历史对话；快捷问题隐藏或弱化 |
| 清除当前Tab | 仅清除当前Tab历史，不影响其他Tab |
| 关闭弹框 | 不清除任何Tab历史 |

### 5.3 AI故障单状态

| 状态 | 说明 | 可操作 |
| --- | --- | --- |
| 对话收集中 | Agent正在收集字段 | 继续对话、选择设备、上传附件 |
| 预览待确认 | Agent已生成只读预览 | 生成待提交单、继续对话、取消 |
| AI待提交 | Agent已生成待提交故障单 | 在故障上报页面详情、编辑、提交、删除 |
| 待接单 | 用户在故障上报页面提交后进入正式流程 | 按既有故障流程处理 |

### 5.4 编号规则

1. AI生成的待提交单据使用正式故障编号。
2. 编号在AI待提交生成时产生。
3. 单据最终提交后，不再额外标识来源为“运维Agent”。
4. AI待提交单据不设置自动过期时间。

## 6、异常处理

### 6.1 权限异常

| 场景 | 处理 |
| --- | --- |
| 用户无AI悬浮框权限 | 不展示运维Agent入口 |
| 用户有AI悬浮框权限但无故障上报权限 | 进入AI故障上报Tab后，Agent自动用对话形式提示：可咨询和整理，但不能生成AI待提交单据 |
| 用户无目标业务页面权限 | 操作指引可解释原因，但不代替用户执行受限操作 |

### 6.2 AI故障上报异常

| 场景 | 处理 |
| --- | --- |
| 未选择设备 | 提示必须先选择1台设备 |
| 用户一次描述多台设备 | 提示每次仅支持上报1台设备，引导重新选择 |
| 缺少故障现象 | 继续追问，不生成预览 |
| 未选择紧急程度 | 默认“紧急”，并提示可在故障上报页修改 |
| 非必填字段缺失 | 仅在生成预览前提示一次，不阻断生成 |
| 附件上传失败 | 保留已收集文本信息，提示附件未上传成功，可稍后在故障上报页补充 |
| 生成AI待提交失败 | 保留当前对话和预览，提示稍后重试 |

### 6.3 智能问数异常

| 场景 | 处理 |
| --- | --- |
| 问题条件不足 | Agent主动追问关键条件 |
| 未说明时间范围 | 默认近30天，并说明可调整 |
| 后台API失败 | 保留上一次成功结果，提示当前查询未更新 |
| 返回数据为空 | 明确说明无匹配数据，并提示可放宽条件 |
| 导出失败 | 提示导出失败，可重试或复制结果 |

### 6.4 操作指引异常

| 场景 | 处理 |
| --- | --- |
| 无法识别用户意图 | 追问用户想完成的具体目标 |
| 涉及跨页面流程 | 不立即跳转，先解释路径并征得用户确认 |
| 用户询问受权限限制操作 | 说明限制原因和可联系的角色 |

## 7、验收标准

### 7.1 全局入口验收

| 编号 | Given | When | Then |
| --- | --- | --- | --- |
| A-01 | 用户有AI悬浮框权限 | 打开任意业务页面 | 页面右下角展示运维Agent悬浮入口 |
| A-02 | 悬浮入口处于默认状态 | 用户拖拽入口 | 入口可纵向移动，松手后吸附到右侧 |
| A-03 | 悬浮入口3秒无操作 | 系统计时结束 | 悬浮入口变为半透明 |
| A-04 | 用户点击悬浮入口 | 弹框打开 | 右侧Agent弹框展示，悬浮入口隐藏 |
| A-05 | 弹框已打开 | 用户点击关闭 | 弹框关闭，悬浮入口恢复显示，历史对话不清除 |

### 7.2 Tab与历史验收

| 编号 | Given | When | Then |
| --- | --- | --- | --- |
| B-01 | 用户首次打开Agent | 查看弹框 | 默认进入AI故障上报Tab |
| B-02 | 用户切换到智能问数Tab后关闭弹框 | 再次打开Agent | 默认回到智能问数Tab |
| B-03 | 三个Tab均有历史对话 | 用户清除当前Tab | 仅当前Tab历史被清除，其他Tab不受影响 |

### 7.3 AI故障上报验收

| 编号 | Given | When | Then |
| --- | --- | --- | --- |
| C-01 | 用户进入AI故障上报Tab | 首次进入 | Agent自动提示“我可以帮你通过对话生成待提交故障单。请先选择设备。” |
| C-02 | 用户点击选择设备 | 打开设备选择器 | 展示设备编号、设备名称、所属车间、所属产线 |
| C-03 | 用户尝试上报多台设备 | Agent识别多设备意图 | 提示每次仅允许上报1台设备 |
| C-04 | 必填字段未满足 | 用户请求生成预览 | Agent继续追问缺失必填字段 |
| C-05 | 必填字段满足但非必填字段缺失 | 用户请求生成预览 | Agent仅提示一次非必填缺失项，并允许生成预览 |
| C-06 | 预览已生成 | 用户查看预览 | 所有预览字段不可直接编辑 |
| C-07 | 用户需要修改预览内容 | 用户点击继续对话 | Agent通过对话更新预览字段 |
| C-08 | 用户点击生成待提交单 | 生成成功 | 产生AI待提交故障单，并使用正式故障编号 |
| C-09 | AI待提交单已生成 | 用户进入故障上报页面 | 可对该单据执行详情、编辑、提交、删除 |
| C-10 | 用户提交AI待提交单据 | 提交成功 | 单据状态流转为待接单 |

### 7.4 智能问数验收

| 编号 | Given | When | Then |
| --- | --- | --- | --- |
| D-01 | 用户输入完整问数问题 | Agent处理 | 返回文本、指标卡、图表或表格结果 |
| D-02 | 用户未说明时间范围 | Agent处理 | 默认按近30天查询，并提示可调整 |
| D-03 | 用户问题条件不足 | Agent处理 | 主动追问缺失条件 |
| D-04 | 用户继续追问 | Agent处理 | 继承上一轮条件并重新计算 |
| D-05 | 用户点击复制结果 | 操作成功 | 问数结果复制成功 |
| D-06 | 用户点击导出Excel | 操作成功 | 生成可下载或可获取的Excel结果 |
| D-07 | 后台API失败 | Agent处理 | 保留上一次成功结果，并提示当前查询未更新 |

### 7.5 操作指引验收

| 编号 | Given | When | Then |
| --- | --- | --- | --- |
| E-01 | 用户进入操作指引Tab | 查看页面 | 展示当前页面上下文 |
| E-02 | 用户询问当前页面怎么用 | Agent处理 | 返回简短操作说明 |
| E-03 | 用户需要详细步骤 | 点击展开详细步骤 | 返回更完整的分步说明 |
| E-04 | 用户问题涉及跳转 | Agent处理 | 先确认用户目标，不直接跳转 |
| E-05 | 用户点击复制步骤 | 操作成功 | 操作步骤被复制 |
