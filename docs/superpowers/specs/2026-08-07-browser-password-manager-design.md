# 浏览器密码管理器设计

## 目标

保留登录页的“记住密码”文案，不显示浏览器密码管理的辅助说明；前端和后端均不得保存、读取或回填明文密码。

## 方案

- 登录表单继续使用原生 `<form>` 提交语义。
- 账号输入框提供稳定的 `name="username"` 和 `autocomplete="username"`。
- 密码输入框提供稳定的 `name="password"` 和 `autocomplete="current-password"`。
- “记住密码”复选框保持受控视觉状态，不渲染辅助说明，也不进入请求、存储或会话逻辑。
- 登录成功后仍只由现有认证逻辑保存访问令牌；退出仍清除访问令牌。

## 边界

- 不将密码写入 localStorage、sessionStorage、Cookie、IndexedDB 或业务 API。
- 不修改认证接口、权限、数据库迁移、令牌时长、部署配置或 RAGFlow 相关资源。
- Chrome 是否提示保存或自动填充凭据取决于用户设置和受信任 HTTPS 证书；应用不伪造该行为。

## 验收

1. 登录表单可被浏览器识别为用户名和当前密码表单。
2. 勾选或取消“记住密码”不会改变登录请求体，也不会产生密码持久化。
3. 登录页测试覆盖表单属性、复选框保留及不渲染辅助说明；现有登录、锁定、退出行为保持不变。
