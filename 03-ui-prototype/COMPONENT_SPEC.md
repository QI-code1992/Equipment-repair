# Component Specification

- Baseline: Candidate v1.0
- Status: Awaiting Stage 3 approval

| Component | Required variants | Required states |
|---|---|---|
| Sidebar navigation | active, nested, hidden | authorized, forbidden |
| Status badge | normal, warning, danger, neutral | text + color |
| Health score card | score, grade, components | loading, error, unavailable |
| Data table | compact, selectable, paged | loading, empty, error, permission |
| Form field | text, select, date, attachment | required, invalid, disabled, saving |
| Agent floating entry | default, idle, dragged | open, closed, permission hidden |
| Agent drawer | three tabs, history | collecting, preview, querying, error |
| Evidence card | citation, confidence, safety | loading, no-source, review-required |
